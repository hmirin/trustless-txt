How it works

  1. Encrypted in your browser

    A fresh 18-character key drawn from crypto.getRandomValues is stretched with PBKDF2-SHA256 (600,000 iterations) to a 256-bit AES-GCM key. Effective brute-force cost ≈ 2128. Encryption happens before any network call.

  2. Server stores ciphertext only

    The Worker stores {id, ciphertext, created_at, expires_at}. It cannot read plaintext; a scheduled job purges expired rows every 15 minutes.

  3. Key travels in the URL fragment

    The part after # is never sent over HTTP. The server cannot see it, log it, or hand it to anyone.

  4. Auto-expires, then gone

    After expiry, the server stops returning the ciphertext; the scheduled job then deletes it. Once deleted, no recovery is possible — the key alone is useless without the data.
